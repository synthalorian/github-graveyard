# Contributing to GitHub Graveyard

First off, thanks for considering contributing! 🪦

## How to Contribute

1. **Fork** the repository
2. **Create a branch** (`git checkout -b feature/amazing-thing`)
3. **Commit** your changes (`git commit -m 'Add amazing thing'`)
4. **Push** to the branch (`git push origin feature/amazing-thing`)
5. **Open a Pull Request**

## Ideas for Contributions

- 🎨 Better tombstone models or textures
- 🌫️ Improved fog/atmosphere effects
- 🔊 Spooky ambient audio
- 📊 More repo data on tombstones (issues, forks, etc.)
- 🏃 Sprint mechanic or crouch
- 🕯️ Lanterns or other light sources in the scene
- 🦇 Flying bats or other animated creatures
- 📱 Mobile touch controls

## Code Style

- Use vanilla JavaScript (no frameworks)
- Keep the main file modular where possible
- Comment complex 3D math or raycasting logic
- Test with `npm run build` before submitting

## Reporting Bugs

Open an issue with:
- Browser and OS
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Questions?

Open a [Discussion](https://github.com/yourusername/github-graveyard/discussions) or ping us in an issue.
